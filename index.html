Home Server Calendar

A private, non-commercial tool used by one household. It runs on the family's own home server and keeps appointments on the family's shared Google Calendar up to date. It is not offered to the public.

Privacy policy

  • What it accesses: with the account owner's permission, it adds and updates events on the household's Google Calendar, and reads appointment emails that family members forward to the owner's Gmail.
  • How data is used: only to keep the family calendar accurate. Nothing else.
  • Storage: data stays on the household's own server and in the owner's Google account.
  • Sharing: data is never sold, shared with third parties, or used for advertising or AI training.
  • Google API data: use of information received from Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements.
  • Revoking access: remove "Home Server Calendar" at myaccount.google.com/permissions at any time.
